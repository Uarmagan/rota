## Findings considered and rejected

- Fixed UTC offsets/DST: simulated availability intentionally uses fixed local-wall-clock
  modeling; changing it would reopen a documented architecture choice.
- Server-side ranking or facts enrichment: rejected by ADR 0007; the client is the one
  ranking owner.
- Prose feedback retry: rejected by ADR 0007; deterministic fallback is intentional.
- Authentication as an MVP prerequisite: accounts/auth are explicitly out of scope;
  abuse/resource controls remain planned in 005.
- Adopt Hono now: the current three Web-standard handlers do not justify a second router.
- Add a component library now: unnecessary for the scoped native editors and contrary to
  current roadmap sequencing.
- Major AI SDK/TypeScript migrations: no current EOL, security, or removal pressure was
  found; not worth adding migration risk before M6.
